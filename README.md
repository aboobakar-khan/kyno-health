# Kyno Health — Caretaker at Home & Hospital-Grade Healthcare in Gurgaon

A modern full-stack healthcare platform for **Kyno Health**, providing certified 12-hour & 24-hour live-in caretakers, elderly care, bedridden patient assistance, and 20-minute emergency doctor home visits across Gurgaon & Delhi NCR.

Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, and modular JSON content architectures.

**Developer / Maintainer:** [Aboobakar Khan](https://www.linkedin.com/in/aboobakarkhan/)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Production Build & Lint
```bash
npm run lint
npm run build
```
